# Repository instructions

## Language

- Write all new or updated documentation, code comments, docstrings, and explanatory comments in configuration files in English.
- Keep `README.md` as the canonical English README.
- Preserve `README.zh-CN.md` as the explicit Chinese translation exception. Keep its substantive content aligned with `README.md` when the project description, scope, architecture, or roadmap changes.
- Maintain reciprocal language links between the two README files.
- Do not create additional non-English documentation unless the user explicitly requests it.
- This policy governs repository content; conversational replies may follow the user's language.
